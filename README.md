# wktimer

근무시간 계산하기 

<br>

## 기능

**이번 달 근무시간 계산**
- 이번 달 기준근무시간과 어제까지의 합계근무시간을 입력하면 남은 근무시간과 평일 날짜 수, 1일당 평균 필요 근무시간을 계산
- 주말 및 한국 공휴일을 제외한 실제 평일 기준 계산

**오늘 근무시간 계산**
- 출근 시각과 비근무시간(점심·외출 등)을 입력하면 현재 시점까지의 실근무시간을 계산

**퇴근 시뮬레이션**
- 퇴근 예정 시각을 입력해 해당 시각에 퇴근할 경우의 근무시간을 미리 확인

<br>

## 기술 스택

- **프론트엔드:** Vue 3 + TypeScript + Vite (PWA)
- **저장/인증:** Supabase
